# Waleed Ahmed — Portfolio

Personal portfolio site for Waleed Ahmed, Materials Engineer and researcher.

- Live: https://waleeds.tech/ (via Cloudflare Pages)
- Stack: React + TypeScript + Vite + GSAP
- Design direction: Inexa-inspired, rebuilt with original code

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build   # output: dist/
```
